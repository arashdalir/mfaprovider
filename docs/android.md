# Building for Android

## What you need
| Tool | Notes |
| --- | --- |
| Android SDK | Android Studio's SDK is enough. The platform in `compileSdk` (`app/src-tauri/gen/android/app/build.gradle.kts`) is fetched by Gradle once the SDK licences are accepted. |
| Android NDK `29.0.14206865` | Install with Android Studio's SDK Manager or `sdkmanager "ndk;29.0.14206865"`. CI uses the same version. |
| JDK 21 | Android Studio's bundled one (`jbr`) works. |
| Rust target | `rustup target add aarch64-linux-android` (real phones; add `x86_64-linux-android` for an emulator). |
| Windows only | Switch on **Developer Mode**: the Tauri CLI creates a symbolic link to the native library. |

Set `ANDROID_HOME` (the SDK), `NDK_HOME` (the NDK folder) and `JAVA_HOME` (the JDK).

## Build the debug APK
From `app/`:

```sh
pnpm install
pnpm tauri android build --debug --target aarch64 --apk
```

The APK is `src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk`.

To keep it small (about 22 MB instead of 150 MB), set `CARGO_PROFILE_DEV_DEBUG=0` and `CARGO_PROFILE_DEV_STRIP=symbols`. If the APK stays large afterwards, delete `src-tauri/gen/android/app/build` and build again.

## Install and start
```sh
adb install -r <apk>
adb shell am start --user 0 -n dev.area_51.android.mfaprovider.debug/dev.area51.android.mfaprovider.MainActivity
```

A debug build has the application id suffix `.debug`. `--user 0` matters on phones with a work profile or private space. Over slow Wi-Fi, use `adb install --no-streaming`; a USB cable is much faster.

## The committed Android project
`app/src-tauri/gen/android` is generated by Tauri and then edited by hand, so it is committed. **Do not run `tauri android init` over it** (ADR-0015). The hand-made changes:
- `app/build.gradle.kts`: `applicationId` (ADR-0015) and the `androidx.biometric` dependency.
- `AndroidManifest.xml`: camera permission (camera optional), `allowBackup="false"`.
- `MainActivity.kt`: `FLAG_SECURE` and system-bar insets.
- `KeystorePlugin.kt`: biometric unlock (ADR-0016).
